# Changelog

## v0.2.0

- Add explicit Desktop, iOS, and Android semantic layout idioms.
- Enforce platform minimum interactive-control heights while preserving one
  shared semantic element tree.
- Parameterize semantic layout gaps by target idiom.

## v0.1.0

- Initial Gio window/frame interpreter.
- Keyed button, checkbox, and editor state.
- Post-frame message dispatch into the Cadence runtime.
- Semantic element and style lowering.
- Explicit cancellable effect handler.
