# Changelog

## Quicken Web v0.8.0

- Initial typed browser node, attribute, and event model.
- Escaped SSR and deterministic keyed diff/patch operations.
- Versioned manifests and no-replacement DOM hydration.
- Delegated events, controlled-input reconciliation, IME handling, and focus
  restoration.
- Typed remote command protocol and executor.
- Revisioned live synchronization over WebSocket with long-poll fallback.
- Generic JavaScript loader with application behavior in Go Wasm.
